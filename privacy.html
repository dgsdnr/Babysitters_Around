Политика конфиденциальности Babysitters Around

Это упрощённая версия политики для пользователей. Полная версия проходит юридическую проверку и будет обновлена.

Какие данные мы собираем

Имя, город, фотография, Telegram username — из вашего профиля. Для родителей: по желанию — информация о ребёнке. Для нянь: подробная анкета, которую вы заполняете сами.

Как используются данные

Только для работы сервиса: показа анкет в поиске, передачи заявок между родителем и няней, истории заявок и отзывов. Мы не используем данные в рекламных целях и не продаём их третьим лицам.

Данные о детях

Мы просим не указывать в открытых текстовых полях имя ребёнка, точный адрес проживания или сведения о здоровье. Для возраста ребёнка используется только возрастная категория, без даты рождения.

Хранение и удаление

Вы можете удалить аккаунт в любой момент в разделе «Настройки». Закрытые заявки автоматически удаляются из системы спустя 180 дней.

Связь с нами

По любым вопросам — напишите нашему Telegram-боту Babysitters Around.
